Connect your computer.

Pair your own Mac with Gepetel and it can use it for you — from your private chat only, never from a group. The Mac dials out to Gepetel, so nothing listens on your machine and there is no port to forward.

Download Gepetel for Mac macOS 13 or newer. Signed and notarized by Apple. Nothing else to install.

What it can do today

  • Say whether your computer is on — and what it can currently do.
  • Read a web page on your machine — fetched from your own connection, then boiled down on the Mac to just the passages that answer your question, so the answer comes back fast and cheap instead of a whole page. It also picks up the things a page states in data rather than in words: a phone number, an address, opening hours.
  • Run commands in a sandbox — for the work a chat assistant otherwise guesses at: arithmetic, a CSV, an API call, a quick script. It uses the sandbox built into macOS, and it can see exactly one folder of yours — ~/Gepetel/workspace — and nothing else.

Coming next: your own logged-in Chrome, for things that need a browser.

1Install the app

Open the downloaded Gepetel.dmg and drag Gepetel into Applications (or just open it — it offers to move itself there). It lives in the menu bar at the top of the screen, starts when you log in, and keeps itself up to date.

2Type the code from the chat

In your private chat with Gepetel, say "connect my computer". It replies with a six-digit code. Type it into the box the app shows — or, later, click Gepetel in the menu bar → Connect to Gepetel…

The code lasts ten minutes and works once — if it runs out, just ask again. Gepetel messages you in the chat the moment it's connected. Ask it "is my computer on?" to see for yourself.

3That's it

Everything else is in the menu-bar icon:

  • Let Commands Use the Internet — on by default; turn it off and the sandbox has no network at all.
  • Open Workspace Folder — the one folder commands can see. Working files are tidied after a day; put anything worth keeping in keep/.
  • Check the Sandbox… — runs real commands on your Mac to prove they can't read your files or keys.
  • Disconnect This Mac… — and its key stops working at once.

A sleeping Mac simply shows as offline, and reconnects by itself when it wakes. While it's working on something for you, it won't doze off halfway.

What it can and can't reach

  • Only your own private chat. A paired computer belongs to one chat, and every request is checked against it. No group can reach it, and neither can anyone else's chat.
  • It dials out. Nothing listens on the Mac, no port is forwarded, no tunnel is installed.
  • One credential, on your disk. Pairing stores a device token in ~/Library/Application Support/Gepetel/agent.json, readable only by you. Gepetel's side keeps only a hash of it.
  • Pages, not your files. Reading a page cannot touch your disk, and it refuses addresses inside your home network — so a web page can't talk Gepetel into opening your router.
  • Commands run confined. Your home directory is unreadable to them and the rest of the disk is read-only — no documents, no Keychain, no SSH keys, no browser profile. One command at a time, killed at its time limit, and everything it writes or installs lands in that one folder.
  • Updates are ours, and only ours. The app installs a new version only if it is signed by the same Apple developer account as the one you installed, and notarized by Apple.
  • Off whenever you like. Disconnect from the menu bar, or tell Gepetel in the chat to disconnect it — either way the token stops working.
Prefer the command line?

The app is a wrapper around an open-source agent you can run yourself with Node 22 or newer:

git clone https://github.com/bogdanripa/gepetel.git
cd gepetel/agent
npm install && npm run build
node dist/index.js pair 123456   # your code, not this one
node dist/index.js run
node dist/index.js selftest       # proves the sandbox really is one
node dist/index.js unpair         # revokes this Mac's token

Don't run it alongside the app — they would share one pairing. To take the sandbox off the network, add "shell_network": false to ~/Library/Application Support/Gepetel/agent.json.

Something not working? Tell Gepetel in the chat and ask it to pass a note to its creator. The app's log is under its menu → Show Log.
